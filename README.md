# 현장 위험성평가 AI - 사용자 수정값 공유 학습 버전

## 실제 학습 흐름
1. 사용자가 현장 사진을 등록합니다.
2. AI가 작업환경/위험항목/추가 위험요인/대책을 분석합니다.
3. 사용자가 실제 현장에 맞게 체크박스, 작업환경, 추가 위험요인, 대책을 직접 수정합니다.
4. **이미지 저장** 버튼을 누릅니다.
5. 바로 그 순간의 최종 수정값이 정답 학습사례로 Netlify Blobs에 저장됩니다.
6. 다른 사용자의 다음 AI 분석부터 누적된 정답 사례를 참고합니다.

즉, AI가 처음 낸 답을 학습하는 것이 아니라 **사람이 최종 수정한 뒤 이미지 저장한 결과**를 학습합니다.

## 학습에 저장하는 내용
- 축소한 현장 사진(최대 3장)
- 최종 작업환경: 나대지/전주/강관주/철탑/건물안/터널/옥상/옥탑
- 이미지 저장 시점에 최종 체크된 평가항목
- 사용자가 최종 수정한 추가 위험요인
- 사용자가 최종 수정한 대책
- 기온/체감온도(보조정보)

## 학습 서버에 저장하지 않는 내용
- 협력사/도급사명
- 국소명
- 투입인원
- 연락처
- 서명
- 완성된 위험성평가표 이미지
- 현장 특이사항

## 정확도 안전장치
- 현재 사진의 직접적인 시각근거가 과거 학습사례보다 항상 우선
- 동일 작업환경이라는 이유만으로 과거 위험을 복사하지 않음
- 80% 이상 + 구체적인 사진 근거가 있을 때만 자동 체크
- 맑은 날씨/PPE 정상착용/현장 설명은 추가 위험요인으로 사용하지 않음
- 현장 특이사항은 AI가 쓰지 않고 기존 온도 로직만 사용
- 같은 사진 + 같은 최종 수정값의 중복 학습 방지

## 배포
GitHub 저장소에 ZIP의 파일/폴더 구조를 그대로 업로드합니다.

필수 Netlify 환경변수:
- `GEMINI_API_KEY`

선택:
- `GEMINI_MODEL` (미설정 시 코드 기본값 사용)

이 버전은 `@netlify/blobs`를 이용하므로 `package.json`도 반드시 함께 업로드해야 합니다.


## 이번 버전 추가 규칙
- 현장 특이사항은 **AI 완전 차단**: AI가 생성/수정/덮어쓰기하지 않음
- 현장 특이사항은 기존 **온도 기반 자동 멘트만 유지**
- 추가 위험요인: **10자 이내**
- 대책: **10자 이내**
- 사용자가 직접 수정해도 입력칸에서 10자까지만 허용
- 이미지 저장 시 학습되는 최종 위험요인/대책도 각각 10자로 저장


## 메타 안내문 완전 제거
AI 결과에는 아래 유형의 문장을 출력하지 않습니다.
- 사진만으로 판단이 어렵다는 문장
- 보호구 착용 여부를 판단하기 어렵다는 문장
- 구체적인 작업 방법을 판단하기 어렵다는 문장
- 실제 작업 진행 여부를 판단하기 어렵다는 문장
- 현장 재확인/최종 확인 필요 문장

근거가 부족한 항목은 설명문을 만들지 않고 결과에서 생략합니다.


## 이번 수정
- 현장 특이사항은 온도 로직 전용으로 하드락했습니다.
- AI가 다른 문구를 넣어도 1초 이내 온도 기준 문구로 복원합니다.
- 추가 위험요인/대책은 입력 → AI 반영 → 이미지 생성 → 이미지 저장 → 학습 저장 → 서버 응답 모든 단계에서 각각 10자 이하로 강제합니다.


## LOCK10 v2 확인방법
배포 후 화면의 `추가 위험요인 및 대책` 옆에 **LOCK10 · v2** 표시가 보여야 최신 index.html이 적용된 것입니다.
현장 특이사항에는 **온도 전용 · AI 완전 차단 · v2** 표시가 보여야 합니다.
이 표시가 없으면 Netlify가 이전 index.html을 서비스하고 있는 상태입니다.
